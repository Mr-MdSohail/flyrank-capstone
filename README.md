# CineMatch AI — FlyRank Capstone

Next.js App Router + Tailwind CSS capstone skeleton deployed with continuous preview builds.

## Routes & Architecture
- `/` — Home overview (Server Component)
- `/discover` — AI recommendation & search workspace placeholder (Client Component)
- `/watchlist` — Saved shows tracker placeholder (Client Component)
- `/health` — Server-rendered upstream API health check fetching live data from TVMaze

## Environment Variables
Copy `.env.example` to `.env.local` for local development. Secrets are never committed to Git.
